# Dragon Command Flute

Parent: [Companion Guides](/mod/hydragon/companion-guides-index) | [Home](/mod/hydragon/)

The **Dragon Command Flute** opens your companion roster. Captured full dragons and your Soulbound Miniwyvern use the same roster interface, while active companions receive the commands that fit their role.

## Roster actions

Select a companion card first, then choose the action you need:

| Action | What it does |
|---|---|
| **Summon** | Brings a stored, living companion into the world. |
| **Dismiss** | Stores the active companion safely and ends its current summon. Dismissal is not death. |
| **Locate** | Helps you find the selected companion when it is not beside you. |
| **Revive** | Restores a companion whose card shows confirmed death after you provide the listed materials. Revival returns it to storage; summon it separately. |

The roster can hold unlimited owned full dragons. It has one active full-dragon slot and one active Miniwyvern slot, so one of each can be active together. See [Summoning and Revival](/mod/hydragon/summoning-and-revival) for timing and costs.

## Commands for an active companion

Use the command wheel while the companion is active:

| Command | Player-facing use |
|---|---|
| **Follow** | Have the companion travel with you and return its attention to you. |
| **Hold** | Keep it at its current position until you give another order. |
| **Recall** | Call it back to you and clear its current combat order. |
| **Move** | Point at a location and send it there. |
| **Defend** | Tell it to protect you instead of wandering off after another target. |
| **Attack** | Point at a creature, then issue Attack to make the companion engage that target. |
| **Idle / Wander** | Stop an active order and let the companion idle nearby. |
| **Airborne mode** | Toggle flight or ground mode for a companion that supports it. |

The airborne toggle is shown only where the companion supports it. Miniwyverns use it to switch their own ground or air companion movement; this is NPC locomotion, not a player mount. Nordic Drake and Winged Toxic Hydra use the toggle for their distinct avatar-flight mounting modes, while ground-only Hydra and Rock Drakes remain ground mounts.

## A reliable routine

1. Summon the profile you want from the roster.
2. Set **Follow** while traveling, or **Hold** while setting up a fight.
3. Use **Move** for a precise position, **Defend** for protection, or **Attack** while pointing at a target.
4. Use **Recall** before you cross a dangerous gap or need the companion beside you.
5. Dismiss it when you are finished, or let the full-dragon window expire and store it automatically.
